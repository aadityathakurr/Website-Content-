# HotWax Systems: Apache OFBiz Support and Maintenance page

Preview of the landing page for `https://www.hotwaxsystems.com/services/apache-ofbiz-support-and-maintenance`.

**Live preview:** https://aadityathakurr.github.io/Website-Content-/hotwax-support-and-maintenance-page/

- `index.html` is the whole page in one file (fonts load from Google Fonts; every image is built in), so it opens anywhere.
- It is marked `noindex` and its canonical URL points at hotwaxsystems.com, so this copy stays out of search results.
- The HubSpot build (editable S&M modules) lives in the developer kit, not in this repo.

Run locally:

```bash
python3 -m http.server 8899
# open http://127.0.0.1:8899/
```
