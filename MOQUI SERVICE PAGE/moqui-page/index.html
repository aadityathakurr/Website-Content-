A Modern Framework for Building Enterprise Applications Faster.

Moqui is an open-source Java and Groovy framework for building custom ERP and commerce applications, built around a Universal Data Model and Universal Service Library with reusable business artifacts. It provides one foundation for business automation applications, multi-instance SaaS, and ready-made apps, with built-in REST APIs.
